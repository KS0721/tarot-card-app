## 왜 만들었는가

타로 리딩 앱은 많지만, 대부분 **고정된 카드 해설을 그대로 보여주는 사전** 수준에 머물러 있습니다. 같은 카드를 뽑아도 "연애가 고민인 사람"과 "이직이 고민인 사람"에게는 완전히 다른 이야기가 필요한데, 기존 앱들은 그 차이를 만들어내지 못합니다.

**Arcana Luna**는 이 문제를 해결하기 위해 만들었습니다.

- 사용자의 **질문 맥락**을 AI가 분석하여 **매번 다른 해석**을 생성
- 해석이 끝난 뒤에도 **대화를 이어가며** 더 깊은 통찰을 얻을 수 있음
- 회원가입 없이 즉시 사용 가능, 완전 무료, **개인 기록은 암호화**

## 무엇을 만들었는가

### 78장의 완전한 타로 덱

전통 타로의 모든 카드를 포함합니다.

- **메이저 아르카나 22장** — 인생의 큰 전환점과 영적 여정을 상징 (바보, 마법사, 여사제, 여황제, 황제, 교황, 연인, 전차, 힘, 은둔자, 운명의 수레바퀴, 정의, 매달린 사람, 죽음, 절제, 악마, 탑, 별, 달, 태양, 심판, 세계)
- **마이너 아르카나 56장** — 일상 속 구체적인 상황을 다루는 네 가지 원소
  - **완드(지팡이)** 14장 — 불: 열정, 행동, 도전
  - **컵** 14장 — 물: 감정, 사랑, 관계
  - **소드(검)** 14장 — 공기: 사고, 갈등, 결단
  - **펜타클(동전)** 14장 — 땅: 돈, 건강, 현실

모든 카드는 **정방향과 역방향** 두 가지로 해석됩니다. 역방향은 단순히 "나쁜 의미"가 아니라, 에너지가 차단되었거나 내면화된 상태를 뜻합니다.

## 주요 기능

### AI 해석 — 같은 카드, 다른 이야기

고정된 카드 사전이 아닙니다. AI(Llama 3.3 70B)가 **질문의 맥락, 뽑힌 카드, 배치 위치, 정/역방향**을 모두 고려하여 매번 고유한 해석을 생성합니다.

- "이직해야 할까요?"에서 뽑은 '탑' 카드와
- "연인과 화해할 수 있을까요?"에서 뽑은 '탑' 카드는 **완전히 다른 해석**이 나옵니다

### 대화형 후속 질문

해석이 끝난 뒤 궁금한 점을 **추가로 물어볼 수 있습니다.**
- "이 카드가 정확히 뭘 의미하는 건가요?"
- "추가로 카드를 한 장 더 뽑아볼 수 있나요?"
- AI가 이전 맥락을 기억하고 이어서 대화

### 14가지 스프레드 — 질문에 맞는 배치

| 스프레드 | 카드 수 | 용도 |
|---------|--------|------|
| 원 카드 | 1장 | 오늘의 한마디, 빠른 답 |
| 쓰리 카드 | 3장 | 과거 → 현재 → 미래 |
| 조언 스프레드 | 3장 | 상황 → 장애물 → 해결책 |
| 라인 스프레드 | 5장 | 시간순 흐름 파악 |
| 크로스 스프레드 | 5장 | 핵심 문제 + 주변 맥락 |
| 양자택일 | 5장 | 두 선택지 비교 |
| 예/아니오 | 1장 | 직관적 답변 |
| 타이밍 | 3장 | 언제 행동해야 하는가 |
| 칠성 스프레드 | 7장 | 숨겨진 장애물 포함 분석 |
| 말발굽 스프레드 | 7장 | 인생의 큰 결정 |
| 켈틱 크로스 | 10장 | 가장 깊고 포괄적인 분석 |

질문을 입력하면 AI가 명확도와 주제를 분석하여 **최적의 스프레드를 자동 추천**합니다.

### 점핑 카드

카드를 뽑는 과정에서 **낮은 확률로 예기치 않은 카드가 튀어나옵니다.** 전통 타로에서 셔플 중 카드가 튀어나오는 현상을 디지털로 재현한 것으로, 무의식의 메시지로 해석합니다.

### 질문 자동 분석

사용자가 질문을 입력하면 AI가 분석합니다.
- **명확도 평가** — 구체적일수록 더 정확한 리딩 제공
- **주제 분류** — 연애, 금전, 직업, 건강, 학업, 인간관계 등
- **스프레드 추천** — 질문 유형에 맞는 배치 자동 제안

### 리딩 통계 — 나만의 패턴 발견

누적된 리딩 데이터를 분석하여 개인 패턴을 보여줍니다.
- **타임라인** — 리딩 기록 시간순 조회
- **카드 분포** — 가장 자주 나타나는 카드 통계
- **주제별 분석** — 어떤 고민을 가장 많이 했는지
- **AI 인사이트** — 누적 데이터에서 발견된 패턴 해석

## 개인정보 보호

타로 리딩은 지극히 개인적인 고민을 다루기 때문에, **프라이버시를 최우선**으로 설계했습니다.

- **AES-256-GCM + PBKDF2** 엔드투엔드 암호화
- 사용자의 비밀번호로 암호화 후 저장 — **서버 관리자도 내용 확인 불가**
- 계정 삭제 시 모든 데이터 즉시 삭제
- 리딩 내용에 대한 분석 추적 없음

## 접근 방식

- **회원가입 없이** 바로 리딩 가능 (게스트 모드)
- 기록을 저장하려면 가입: **Google / Kakao / Discord** 소셜 로그인
- **5개 언어** 자동 감지 — 한국어, English, 日本語, 中文, Français
- **PWA** — 모바일 홈 화면에 앱처럼 설치, 오프라인 접근

## 기술 스택

| 구분 | 기술 | 선택 이유 |
|------|------|----------|
| 백엔드 | Python + Flask | 빠른 프로토타이핑, AI API 연동 용이 |
| 프론트엔드 | Vanilla JS + HTML5 + CSS3 | 프레임워크 없이 가볍고 빠른 로딩 |
| AI | Groq API (Llama 3.3 70B) | 고성능 오픈소스 LLM, 빠른 추론 속도 |
| 데이터베이스 | Supabase (PostgreSQL) | 실시간 동기화 + 내장 인증 |
| 인증 | Supabase Auth + OAuth | Google/Kakao/Discord 소셜 로그인 통합 |
| 암호화 | AES-256-GCM + PBKDF2 | 군사급 E2E 암호화로 프라이버시 보장 |
| 배포 | Render (싱가포르) | 아시아 리전 저지연 서빙 |
| PWA | Service Worker + Manifest | 앱 설치 + 오프라인 지원 |
